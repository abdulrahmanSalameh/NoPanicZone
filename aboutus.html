About NoPanicZone

NoPanicZone is a university web development project implemented by Abdulrahman Salameh using HTML, CSS, Bootstrap, and JavaScript.

The project was created to meet the university assignment requirements and practice building a multi-page website. Interview stress was chosen as the theme for its content.

What the Project Includes

  • Multiple pages connected through a navigation menu.
  • Informational content and links to external resources.
  • Images and embedded videos.
  • A JavaScript form with input validation.
  • A report generated from user inputs using predefined conditions.
  • A date and time display.

Project Scope

This is an educational website, not a professional counseling service or a clinically validated assessment tool. The form demonstrates JavaScript logic and does not provide a medical diagnosis.

Success stories shown on this website are fictional examples created for the assignment, not testimonials from real users.

The project met its assignment requirements. Further work on content, design, code organization, and testing would be needed before considering wider use.
